Whole Number:
```java
byte     // [Byte.MIN_VALUE, Byte.MAX_VALUE]                         Byte.SIZE          default=0
short    // [Short.MIN_VALUE, Short.MAX_VALUE]                       Short.SIZE         default=0
int      // [Integer.MIN_VALUE, Integer.MAX_VALUE]                   Integer.SIZE       default=0
long     // [Long.MIN_VALUE, Long.MAX_VALUE]                         Long.SIZE          default=0
```

Real Number:
```java
float    // [Float.MIN_VALUE, Float.MAX_VALUE]                        Float.SIZE        default=0.0
double   // [Double.MIN_VALUE, Double.MAX_VALUE]                      Double.SIZE       default=0.0
```

Single Character:
```java
char     // [(int) Character.MIN_VALUE, (int) Character.MAX_VALUE]    Character.SIZE    default=0
```

Boolean Value:
```java
boolean  // [Boolean.FALSE, Boolean.TRUE]                                               default=false
```

*non null*
