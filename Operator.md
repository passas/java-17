· Operator manipulate operands

Math operators:
```Java
+      // Addiction ; String Concatenation
-      // Subtraction
*      // Multiplication
/      // Division
%      // Modulo
```

```Java
int one = 1;

one + one;    // 2
one++;        // 2
++one;        // 2
one += one    // 2
``

Logical operators:
```Java
==        // Equality
!=        // Inequality
>         // Superiority
<         // Inferiority
>=        // Superiority or equal
<=        // Inferiority or equal
&&        // Logical AND
||        // Logical OR
!         // Negation
```
